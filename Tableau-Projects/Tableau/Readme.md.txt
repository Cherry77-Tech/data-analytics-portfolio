# UK Alcohol Mortality Intelligence Dashboard

## Project Overview
An interactive Tableau dashboard analyzing UK alcohol-specific mortality from 2001 to 2021. The dashboard explores mortality trends, differences between males and females, geographic variation, and the leading causes of alcohol-specific deaths.

## Key Insights and Visualizations
- Total deaths 9,641
- Leading cause Alcoholic liver disease
- Male-to-female mortality ratio 1.928
- Change since 2001 69.11%
- Mortality trends Annual comparisons from 2001 to 2021
- Country comparison England, Scotland, Wales, and Northern Ireland
- Leading causes Ranking of the top alcohol-specific causes of death

The figures above reflect the dashboard screenshot and should be verified against the underlying dataset before publication.

## Analytical Purpose
The dashboard supports exploration of long-term mortality patterns and differences across demographic groups and UK countries. It provides a visual summary of the distribution of recorded alcohol-specific deaths and highlights the causes contributing most to the reported total.

## Data Source and Limitations
The analysis covers 2001–2021. The original dataset, source organization, definitions, and data preparation methods should be documented before publication. The dashboard presents descriptive patterns and does not, by itself, establish causal relationships.

## Reproducing the Dashboard
1. Download or clone this repository.
2. Open the Tableau workbook in Tableau Desktop.
3. Reconnect the data source if Tableau reports a missing file.
4. Verify that the filters, KPIs, and visualizations work as expected.
