# Flight Data Analytics Dashboard

## Project Overview
An interactive Power BI dashboard designed to analyze airline flight performance, delays, cancellations, and on-time operations. The dashboard summarizes flight activity and compares performance across cities, airlines, weekdays, and cancellation reasons.

## Key Performance Indicators
- Total Flights
- Delayed Flights
- On-Time Flights
- Flight delays by airline and day of the week
- Total flights by city
- Cancelled flights by cancellation reason

## Tools & Technologies
- **Power BI Desktop** – Dashboard development and visualization
- **Power Query** – Data transformation and preparation
- **CSV / Excel data files** – Source data

## Dashboard Features
- Executive KPI cards for overall flight performance.
- Monthly trends for delays and on-time flights.
- City-level comparisons of total flights.
- Airline-level analysis of delayed flights.
- Cancellation analysis by reason.
- Weekday comparisons of flight delays.
- Flight status breakdown across cancelled, delayed, and on-time flights.

## Purpose
The project demonstrates practical skills in data preparation, data modeling, KPI analysis, and interactive dashboard development using Power BI.

## Data Note
The dashboard uses flight records and supporting airline, airport, and cancellation-code reference data. Interpret the results within the scope and time period of the supplied dataset.
